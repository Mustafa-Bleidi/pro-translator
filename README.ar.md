## ماذا تفعل المهارة؟

تكتب تاغ اللغة، مثل `--ar` أو `--es` أو `--ja`، مع الملف أو النص، فيترجمه Claude كما يترجمه مكتب ترجمة محترف:

- **المعنى أولًا**: لا ترجمة حرفية، بل نص يبدو كأنه كُتب بلغة الهدف أصلًا.
- **التنسيق محفوظ**: تُعدَّل ملفات DOCX وPPTX وXLSX على مستوى XML، فتبقى الأنماط والجداول والصور والترويسات والتذييلات والحواشي كما هي، ويُضبط الاتجاه من اليمين إلى اليسار تلقائيًا للعربية والأردية.
- **لا شيء يُكسر**: الأرقام والأكواد والروابط والمتغيّرات والمعادلات والمراجع محمية، وتتحقق منها سكربتات آلية.
- **مصطلح واحد للمفهوم الواحد** في المستند كله، مع دعم قاموس مصطلحات خاص بك.
- **مراجعة ثانية إلزامية** تصنّف الأخطاء إلى حرجة وكبيرة وبسيطة، وتنتهي بتقرير تحقق.
- **`--humanize`**: يعيد صياغة الناتج ليبدو كتابة بشرية طبيعية دون أن يغيّر المعنى.
- **الصور التي تحتوي نصًا لا تُلمس إطلاقًا.**

## اللغات وتاغاتها

| التاغ | اللغة | المتغيّرات |
|---|---|---|
| `--ar` | العربية الفصحى | — |
| `--en` | الإنجليزية | `--en-us` · `--en-gb` |
| `--zh` | الصينية | `--zh-cn` مبسطة · `--zh-tw` تقليدية · `--zh-hk` |
| `--es` | الإسبانية | `--es-419` · `--es-es` · `--es-mx` |
| `--hi` | الهندية | — |
| `--fr` | الفرنسية | `--fr-fr` · `--fr-ca` |
| `--pt` | البرتغالية | `--pt-br` · `--pt-pt` |
| `--ru` | الروسية | — |
| `--bn` | البنغالية | `--bn-bd` · `--bn-in` |
| `--ur` | الأردية | `--ur-pk` · `--ur-in` |
| `--id` | الإندونيسية | — |
| `--de` | الألمانية | `--de-de` · `--de-ch` · `--de-at` |
| `--ja` | اليابانية | — |
| `--tr` | التركية | — |
| `--ko` | الكورية | — |

تعمل أيضًا الأسماء البديلة مثل `--عربي` و`--arabic` و`--español` و`--中文`. الترجمة ممكنة من أي لغة من هذه اللغات إلى أي لغة أخرى، وتُكتشف لغة المصدر تلقائيًا، أو تحددها بنفسك بـ `--from=xx`.

## تاغات التحكم

| التاغ | الوظيفة |
|---|---|
| `--humanize` | صياغة بشرية طبيعية بثلاثة مستويات: `=light` والعادي و`=deep`. يعمل وحده دون ترجمة أيضًا |
| `--from=xx` | تحديد لغة المصدر |
| `--formal` / `--casual` | أسلوب رسمي أو ودّي |
| `--domain=legal\|medical\|tech\|…` | تحديد المجال (قانوني، طبي، تقني…) |
| `--localize` | تكييف صيغ الأرقام والتواريخ وعلامات الاقتباس مع البلد (القيم لا تتغير) |
| `--glossary=FILE.csv` | فرض قاموس مصطلحاتك |
| `--bilingual` | الأصل والترجمة جنبًا إلى جنب |
| `--review` | مراجعة ترجمة موجودة بدل الترجمة من جديد |
| `--quick` / `--report` | مسار مختصر / تقرير تحقق كامل |

## أمثلة

```text
/pro-translator --ar report.pdf
/pro-translator --es --fr --de manual.docx        ← ثلاثة ملفات منفصلة
/pro-translator --en --humanize                   ← ترجمة نص عربي إلى إنجليزية طبيعية
/pro-translator --humanize                        ← تحسين نص عربي دون ترجمة
/pro-translator --ar --glossary=terms.csv --report contract.docx
```

## عن `--humanize`

يزيل المُحسِّن علامات النص الآلي: الترتيب المنقول حرفيًا، وتكديس أدوات الربط مثل «علاوة على ذلك… بالإضافة إلى ذلك…»، والعبارات الجاهزة مثل «تجدر الإشارة إلى أن» و«في عالمنا اليوم»، وكثرة «يتم» و«قام بـ»، والإيقاع الرتيب. ثم يعيد الكتابة بتدفّق لغوي طبيعي وأدوات ربط متنوعة حسب المعنى.

يعمل المُحسِّن تحت **قفل المعنى**: لا معلومة جديدة، ولا حذف لشرط أو تحفّظ، ولا تغيير في المصطلحات. ولا يستخدم حيلًا تُفسد المستند، مثل الأخطاء المتعمّدة أو الحروف المخفية أو الحروف الشبيهة. الهدف كتابة جيدة فعلًا. أدوات كشف الذكاء الاصطناعي غير دقيقة، وقد تصنّف نصوصًا بشرية على أنها آلية، لذلك لا تعد المهارة بأي نتيجة في هذه الأدوات.
